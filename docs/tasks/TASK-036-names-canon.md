# TASK-036 — единое написание имён и названий (罗塞尔, 阿尔杰, 迪伦, 苏勒, 罗珊, 黑荆棘, 终末猎杀) и имена из глоссария в `-ExportNew`

## Проблема (анализ 17.10)
В итогах пачек TASK-034 агенты `ru-translator` писали одно и то же имя по-разному: «Роселл/Россель/Росель», «Альджер/Алджер», «Диллон/Дилан», «Финальная/Последняя охота», «сул/сулеры», «Розанна/Лошань», «Чёрный Терновник/Чёрные Тернии». Агенты жаловались, что имён нет в глоссарии, хотя часть из них там есть.

### Первопричина 1: `-ExportNew` не видит имена внутри составных записей
`tools/GlossaryCheck.ps1:352-365` собирает `names` из `characters_and_factions`, `locations_and_geography`, `terms_and_items` и `pathways_and_sequences`. Затем `:391-393` ищет `cn` записи **целиком** как подстроку `source_cn`.
- У членов Клуба Таро `cn` составной: `倒吊人 (阿尔杰·威尔逊)` (`source/glossary/characters_and_factions.json:5`). Строка с одним `阿尔杰` его не содержит, и агент не получает «Элджер». То же для Клейна (`克莱恩`), Одри, Деррика, Эмлина, Форс, Каттлеи и Леонарда. Найдётся только Сио: у неё есть отдельная запись `休·迪尔查`.
- Полное имя `X·Y` тоже не делится: `阿兹克·艾格斯` не даёт `阿兹克`.
- `黑荆棘` есть только в составе `黑荆棘安保公司` (`locations_and_geography.json:18`). К тому же у этой записи неверный `ru`: «Улица Блэкторн» при `en` «Blackthorn Security Company».
- Глоссарии в формате терминов (`marionettes.json`, `autochess_fetters.json`, `ui_traintrade.json`) в `names` не попадают вовсе.

### Первопричина 2: части имён нет ни в одном глоссарии
`罗塞尔`, `迪伦`, `苏勒`, `罗珊` и `终末猎杀` не найдены ни в `source/glossary/*.json`, ни в `docs/GLOSSARY.md`.

### Первопричина 3: имена не проверяются
`-Import` сверяет только термины `-Glossary` (по умолчанию `combat_stats.json`), поэтому расхождение имён проходит молча. За TASK-034 это стало видно, потому что за 2 дня перевели 8 970 строк.

### Первопричина
1. **Ложное совпадение по `cn`.** `cn_exclude` у 罗塞尔 пуст (`source/glossary/names_canon.json:15`), а `tools/GlossaryCheck.ps1:129` ищет `cn` подстрокой, поэтому 格罗塞尔 считается 罗塞尔. Строки с «Гроссел-» попадают в B по `росс?ел`.
2. **Ложное совпадение по `ru`.** `ru_match` 罗塞尔 `розел[ьяюе]` находится внутри «Г**розел**ь», поэтому 5 строк с «Грозель/Грозеля» были в `ok`. По этой же причине `-Import` принял ошибочную замену в batch_005:020991.
3. **Маскировка канона берёт термины, которые в строке только X.** `GlossaryCheck.ps1:144-146` вырезает канон всех терминов из `$found`, хотя у 罗塞尔 в этих строках корзина X (`:138`). После добавления 格罗塞尔 маска `розел[ьяюе]` вырежет «розель» из «Грозель», и запрещённый вариант `гроз+[еэ]л` не найдётся: строка уйдёт в C, а не в B.
