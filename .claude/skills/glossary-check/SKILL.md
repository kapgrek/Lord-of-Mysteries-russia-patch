# Сверка перевода с глоссарием

Инструмент — `tools/GlossaryCheck.ps1` (без ИИ). Корзины: `ok` — канон есть, запрещённых вариантов нет; `A` — короткая подпись (`source_cn` = ровно термин), которую можно заменить каноном; `B` — известный неверный вариант; `C` — ни канона, ни варианта (перефраз, машинный мусор, ложное совпадение); `S` — служебный ключ (`_数值`, `_百分比`, латиница с `_`) или пустой `ref_en`, не правится; `E` — перевода нет; `X` — термин только внутри `cn_exclude`.

## Шаги
1. **Отчёт «было»:** `powershell -File tools\GlossaryCheck.ps1 -Report -ReportFile temp\glossary_report_before.md` (можно `-Terms 穿刺,破防`). Таблица в консоли, список строк по корзинам — в `.md`, цифры — в `.json` рядом.
2. **Короткие подписи:** `powershell -File tools\GlossaryCheck.ps1 -FixShort`. Печатает «было → стало» по каждой строке и пишет батчи (UTF-8 без BOM, LF, меняется только `target_ru`).
3. **Отчёт «стало»:** снова `-Report` (по умолчанию `temp\glossary_report.md`).
4. **Сводка пользователю:** таблица до/после, число замен FixShort, сколько строк осталось в `B` и `C`. Строки `B`/`C` правятся скиллом `translate-chunk`.

## Правила
- Термины и запреты правятся только в `source/glossary/combat_stats.json`; после правки — `-BuildDoc` (пересобирает `docs/GLOSSARY.md`).
- Если `C` содержит повторяющийся неверный вариант, добавить его в `forbidden` термина (регулярка без учёта регистра), чтобы он попадал в `B`.
- Ложные совпадения по `source_cn` — в `cn_exclude` (подстрока вырезается до поиска термина).
- После изменений батчей: `tools\ShardCompiler.exe` и `tools\VerifyBatch.ps1` (хук Stop делает это сам).
