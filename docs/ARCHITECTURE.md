Техническое описание механизмов загрузки, подмены данных, блочного патчинга и рантайм-перехвата в русской версии патча.

```
[Официальный pakchunk0-Windows.pak]
             │
             ▼ (Смещение 427225161: 4 660 байт моста Oodle)
[LaunchInstance.native-bridge.padded.oodle]
             │
             ▼ (Запуск внешнего скрипта)
[Binaries/Win64/lua/Launch/Base/CPDDTranslation.lua]
             │
             ▼ (Загрузка внешнего лоадера)

```

## 1. No-Injection Bootstrap (Безопасное внедрение)

Патч не использует инъекцию DLL, перехват адресов в памяти (memory hooking) или подмену Direct3D библиотек. Все модификации работают через стандартную файловую подсистему Unreal Engine 5.

1. **Точечный патч `pakchunk0-Windows.pak`:**
   * Смещение: `427225161`.
   * Размер блока: `4 660` байт.
   * Исходный SHA-256: `566e72d677fc974ab172eb71a34cdc6623f1e0dd19d978de812a76a1820b7fc7`.
   * Патченый SHA-256: `c031726986e09358bb18ff8a2b8ee5f0b4e65ce8ae8331eed2d7575c80b7efa9`.
   * Патчит стартовый модуль `LaunchInstance.lua`, добавляя строку вызова внешнего моста `CPDDTranslation.lua`.

2. **Мост инициализации `CPDDTranslation.lua`:**
   * Получает путь к директории сохранения: `ProjectSavedDir() .. "/Mods/bootstrap.lua"`.
   * Выполняет `bootstrap.lua` в изолированной среде `xpcall`.

---

## 2. Мод-лоадер `bootstrap.lua`

* Регистрирует кастомный поисковик `external_searcher` на 1-ю позицию в `package.loaders`.
* Реализует два типа подмены:
  1. **Alias (полная подмена модуля):** подменяет `Launch.I18n.zh`, `DebugConst.lua` и другие конфигурационные скрипты на файлы из `Saved/Mods/lua/`.
  2. **Overlay (динамическое наложение):** загружает оригинальный файл игры, после чего поверх таблицы `.data` накатывает строки из локализованной базы данных. Это предотвращает потерю служебных системных ключей при обновлениях игры.

---

## 3. Система рантайм-перевода (1 024 шарда)

Для динамического перевода более 130 000 всплывающих подсказок, уведомлений сервера и боевых сообщений используется шардированный кэш:
* Строка оригинала пропускается через 32-битный алгоритм хеширования **FNV-1a**:
  * `hash = (hash ^ byte) * 16777619`.
* По первым трем шестнадцатеричным символам хеша вычисляется номер шарда от `000` до `3ff` (1 024 шарда).
* Модуль загружается лениво (on-demand) и кэшируется в кольцевом буфере LRU (до 128 активных шардов в памяти).

---

## 4. Блочный патчинг IoStore (`BakedText`)

Текстуры интерфейса и виджеты UMG компилируются в контейнеры `.ucas`:
* Файл `Saved/Mods/BakedText/blocks.bin` (39.17 МБ) содержит 2 949 блоков.
* Патчер осуществляет точечную запись пропатченных блоков прямо в `.ucas` по смещениям из `manifest.json`.
* Для каждого блока сохранен оригинальный SHA-256 и оригинальные байты, что позволяет вернуть игру в исходное состояние за пару секунд.
