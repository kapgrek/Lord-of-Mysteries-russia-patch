## Первопричина
- **Все пункты — «нет в батчах».** `untranslated.csv` сессии 2112: по Автошахматам **360** записей со статусом «нет в батчах» (stringdb 283, widget 59, data 18). Примеры с id StringDB:
  - `159431065086720` «Hammer the ground to shock the surroundings; becomes faster the longer the battle lasts.» / `怒锤震击周围，受击后越战越快。`;
  - `158469797709312` «All allies gain <HighLight>5%</> Max Health. [Iron and Blood] gain additional Max Health.»; `158469797709824` — то же для «Оплот» (Solid Wall);
  - `153933238544896` «Extraordinary Quest Selection: <HighLight>%d</> seconds» / `非凡任务选择：<HighLight>%d</>秒`;
  - `153933238548224` «Unequip All» / `一键脱下`;
  - `153933238545664` «Fate is yours to decide: Accept an Extraordinary Quest, or claim the current gift immediately.»; `153933238543872` «Points: %s/%s» / `积分：%s/%s`.
  
  P1 (`batch_031_autochess_stringdb`, 556 строк) собирался по сессиям до 2112: экраны подсказки фигуры, выбора Потусторонних заданий и кнопок снаряжения в них почти не открывались. Это недостающие данные, а не поломка.
- **Условия заданий из данных игры с числами** («连续3回合战斗失利», «连续3回合战斗胜利», `src=data`, `ac-class:AutoChess_Reward_Choice_Item.OnRefresh`, `RichText_Description`) приходят уже с подставленным числом. В `norm` видно `连续#回合战斗失利`. Проверить, какой путь перевода data-строк с числами уже есть (шаблоны `runtimeFixes.AutoChessSkillTemplates`, `Init.lua:2684+`, или нормализация `#` в поиске шардов). Добавить шаблон тем же способом, а не точные строки на каждое число.
- **«Экипировка в один клик»** — `batch_023` id 113091, `一键装备` / «One-Click Equip». Перевод верный по смыслу, но для маленькой кнопки на поле слишком длинный. «Unequip All» (`一键脱下`) в батчах нет.
  - По-русски про снаряжение правильно «**Надеть**» (надеть на себя / на фигуру), а не «Одеть» (одевают кого-то). Предлагаемая пара: «**Надеть всё**» / «**Снять всё**». Если пользователь выберет иначе, поменять одну строку.
  - `一键装备` может встречаться и вне Автошахмат (экран снаряжения персонажа). Посмотреть в диагностике, где эта строка используется, и если она общая, короткий вариант подходит и там.
- **Термины уже есть** в `batch_028_autochess.json`: `131135`–`131138` — «[Потусторонние задания]», «[Очки заданий]», «дары судьбы». Новые строки переводить в тех же терминах: «Extraordinary Gift» → «Дар судьбы», «Quest Points» → «очки заданий».
- **Обрезка 400 байт** (TASK-012): 29 строк P1 не перевели, потому что диагностика обрезает длинные тексты. Если среди 360 есть обрезанные, увеличить лимит в `AbsruDiagnostics.lua` (только для `src=stringdb`: полный `en`/`cn` пишется один раз на row), чтобы следующая сессия дала полный ключ.
