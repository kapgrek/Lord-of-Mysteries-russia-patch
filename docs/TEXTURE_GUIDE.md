# Руководство по замене текстур и графики (BakedText)

В игре часть надписей запечена прямо в текстуры (`.uasset` внутри IoStore `.ucas` контейнеров):
* Кнопки меню («В бой», «Создать роль», «Настройки»).
* Карты, указатели, газетные иллюстрации.
* Значки способностей и древа талантов.

---

## 1. Архитектура `blocks.bin` и `manifest.json`

В директории `patch_payload/Saved/Mods/BakedText/`:
* `manifest.json` содержит описание 2 949 блоков:
  * `container`: путь к контейнеру (например, `Content/Paks/pakchunk9999-Windows_s0.ucas`).
  * `offset`: байтовое смещение в файле контейнера.
  * `size`: размер блока в байтах.
  * `original_offset`: смещение оригинальных байтов в `blocks.bin`.
  * `replacement_offset`: смещение локализованных байтов в `blocks.bin`.
* `blocks.bin` (39.17 МБ) — бинарный склад блоков:
  * Первая половина файла содержит резервные копии оригинальных китайских блоков.
  * Вторая половина содержит заменяющие локализованные блоки.

## 2. Утилита `BakedTextManager.ps1`

Для работы с запеченным текстом используйте инструмент `tools/BakedTextManager.ps1`:
* **`info`**: общая статистика по хранилищу `blocks.bin` и распределение блоков по контейнерам `.ucas`.
* **`verify`**: поблочная верификация контрольных сумм SHA-256 оригиналов и замен (`-FullVerify` для проверки всех 2 949 блоков).
* **`export`**: извлекает бинарные срезы в `temp/baked_export/` с генерацией файла `export_index.json` (`-IncludeOriginal` выгружает также оригинальные блоки для побайтового анализа).
* **`update`**: запаковывает отредактированный блок обратно в `blocks.bin` с автопаддингом (если блок меньше `b.size`) и пересчетом `replacement_sha256` в `manifest.json`.
* **`patch`**: точечная запись заменяющих блоков прямо в файлы `.ucas` игры с предварительной валидацией оригинальных хешей (полная идемпотентность).
* **`restore`**: безопасный откат файлов игры до 100% исходного состояния за считанные секунды.

Примеры команд:
```powershell
# Экспорт 508 блоков стартового меню и кнопок
powershell -ExecutionPolicy Bypass -File tools/BakedTextManager.ps1 -Action export -ContainerFilter "*10001*" -IncludeOriginal

# Обновление отдельного блока после графической русификации
powershell -ExecutionPolicy Bypass -File tools/BakedTextManager.ps1 -Action update -BlockIndex 0 -InputFile "temp/new_block_0.bin"

# Внедрение локализованных блоков в клиент игры
powershell -ExecutionPolicy Bypass -File tools/BakedTextManager.ps1 -Action patch -GameDir "D:\Games\GMZZLauncher\Game\C7"

# Полное восстановление оригинальных файлов игры
powershell -ExecutionPolicy Bypass -File tools/BakedTextManager.ps1 -Action restore -GameDir "D:\Games\GMZZLauncher\Game\C7"
```

## 3. Спецификация формата и паддинга

* Контейнеры `.ucas` используют сжатие **Oodle Kraken** с блочным шифрованием **AES-256-ECB**.
* Для сохранения целостности смещений и размера контейнеров используется техника фиксированного размера блока:
  * Если локализованный блок меньше исходного размера `b.size`, остаток дополняется 16-байтным циклическим падтерном:
    `0xC8, 0x64, 0x4C, 0x29, 0x33, 0x0A, 0x06, 0x6C, 0xDE, 0x3F, 0xEC, 0xE9, 0xD9, 0x47, 0x0E, 0x84` (зашифрованный нулевой блок AES-256-ECB).
* Установщик `installer/PatcherEngine.exe` автоматически применяет все блоки BakedText на шаге `[4/4]` при установке и корректно возвращает их на оригинальные при удалении.

## 4. Взаимодействие со слоем рантайм-текста

* Строки интерфейса, переведенные через запеченные текстуры (`BakedText`), **не должны дублироваться текстом** в таблицах `RuntimeText` или `StringDB`.
* Если в батчах перевода английский референс (`ref_en`) для такого элемента пустой (`""`), он обязан оставаться пустым и в `target_ru`.
* Это исключает конфликт, при котором рантайм-хук `Init.lua` мог бы принудительно нарисовать текст поверх готовой запеченной графики.
