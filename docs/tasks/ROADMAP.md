## Этапы подробно

### 3. Диагностическая сборка — готово
Данные: `reference/logs/2026-09-25_0312/` (сессия 30 мин, v2.9.1-RU), отчёт в `report/`.
- Хуков 342, из них 262 ни разу не сработали (`dead_hooks.md`).
- Переполнений текста 1608 (`overflow_top.md`, `overflow.csv`).
- Непереведённое: 1584 в UI и 8834 в StringDB (`untranslated.md`).
- Текстур 2500 (`textures.md`).
- В первой (короткой) сессии 46 из 52 переполненных виджетов были с отрицательным `LetterSpacing`, который ставит наш `translateTextWidget`. В сессии 2026-09-25_0312 — 1132 из 1608 (70%).
- API игры: `WidgetTree.GetAllWidgets` недоступен (обход через `view` / `_widgetCache` / `RootWidget` / имена); `os.clock` идёт шагом 1 мс; `Log.Info` в C7.log доходит, `LuaCLogger.Warning` — нет.

### 4. Шрифт
Кириллица через CompositeFont: добавить кириллический диапазон в `Font_Aleo` мод-паком. Проверить, грузит ли игра мод-паки; в `Content/Paks` есть нестандартные `.upak`, нужно проверить их поддержку в FModel/CUE4Parse. Если мод-пак не грузится — запасной путь через Lua. Анализ: [TASK-006-font.md](TASK-006-font.md).

### 5. Подгонка текста по измерению
- Подгонка по `GetDesiredSize` против геометрии (своей и родителя) вместо порогов по длине строки (`Init.lua`, `translateTextWidget`, пороги `> 14` / `> 10` / `> 6`).
- `LetterSpacing` никогда не ниже 0 (сейчас −120 / −60 для кириллицы).
- Затем удалить мёртвые хуки в `Init.lua` по `hooks.json` (статусы `NEVER_CALLED` / `NOT_INSTALLED` во всех сессиях, `CollectDiagLogs.ps1 -Aggregate`).

### 6. Новый установщик (TASK-004)
- WPF в стиле CPDD, опции DPS-метра, чата и Visual Clarity.
- Локальный payload только по ключу `--payload`: сейчас `ResolvePayloadDir` в `installer/Program.cs` жёстко прописывает путь к репозиторию.

### 7. Глоссарий и проверка перевода
- В глоссарии ~70 записей, и в нём есть ошибки: «Церковь Вечной Ночи» → должно быть «Церковь Богини Вечной Ночи».
- Разнобой в батчах: 穿刺 переведён пятью способами, «Хорнацис» встречается в разных формах.
- Порядок: сначала характеристики и боевые термины, потом имена, места, организации.

### 8. Русские картинки
`BakedText` сейчас — английские текстуры CPDD (2949 блоков в `.ucas`). План: выгрузка, OCR, перерисовка с учётом лимита размера блока (замена не может быть больше исходного блока).
