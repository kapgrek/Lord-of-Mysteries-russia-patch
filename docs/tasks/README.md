# Задачи (TASK-файлы)

Аналитический чат (AGENTS.md §3) оформляет результат анализа в файл `TASK-xxx.md`, где `xxx` — следующий свободный номер (`TASK-001.md`, `TASK-002.md`, …). Чат исполнения работает строго по этому файлу.

## Шаблон

```markdown
# TASK-xxx: <короткое название>

## Симптом
Что видит пользователь; версия патча; скриншот или строка лога.

## Первопричина
Подтверждённая логами или дампом: `файл:строка`, фрагмент лога.

## План
1. …
2. …

## Проверка
- Автоматическая: VerifyBatch / VerifyPatch / диффы.
- Чек-лист для пользователя в игре: что открыть, что должно быть видно, какую строку искать в `C7.log`.

## Промпт для чата исполнения
> …
```
