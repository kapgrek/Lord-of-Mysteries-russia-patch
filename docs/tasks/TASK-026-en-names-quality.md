# TASK-026: Английские названия внутри русского текста (качество основного массива)

## Симптом
Пользователь спросил, что ещё можно улучшить в переводе. По новым промахам всё чисто (TASK-025). Главный остаток — качество старого машинного перевода `batch_005`…`batch_026`: в видимых строках остались **английские названия**.

## Данные (2026-09-30, по всем батчам)
- `VerifyBatch`: 140 054 строки, 0 ERR, 1 299 WARN. Из них 336 — «ref_en пуст» (новые строки, норма), ≈600 — «Numbers differ» против `ref_en`. Английский часто взят из другой версии игры, это в основном шум. Реальными могут быть 84 `Closing tag count mismatch` и 32 `{{variant|variant}} count differs`, но они тоже считаются против `ref_en` (раздел R3).
- `GlossaryCheck -Report` (боевые термины): 1 334 строки, B/C = 0. **Чисто.**
- Эвристика «2+ латинских слова по 3+ буквы в `target_ru`»: 2 907 строк, почти все в `batch_005`…`batch_026` (по 106–145 на батч; в `batch_001`…`004` — 15–27, в новых батчах 0–15).
- Эвристика «2+ подряд латинских слова с заглавной» (`Mist Street`, `Old Will's Restaurant`): 2 238 строк, из них ≈264 явно отладочные. Выборка видимых:
  - «Используйте <Highlight>Control Break или Displacement Skill</>, чтобы покинуть центр навыка.»
  - «Есть «Бэкланд Mist», «Тинген Quiet Night», «Constant Iron Heart»…»
  - «После использования вы можете получить <Highlight>Mystery Pryer Outfit</>» (по канону Пути — «Тайный Соглядатай»)
  - «Прибудьте в ресторан <h>Old Will's Restaurant</>», «Разблокирован случайный режим Fool's Dream.», «Следующий Flash Strike будет усилен.», «…в 1 Destiny Moment», «<Highlight>Tarot Uniform Bottoms</>», «Этот шаблон был загружен на Dress-up Plaza».
  - Отладочные (не трогать): «Эффект навыка Auto Chess-85300554», «Че Линпэн - GTA - …», «Зона 2-Bridge ep…», «Заполнитель не отображается — Ball NPC…», «[chenhonghua] …», `[EventSystemV2:…]`.
- Почему не поймал TASK-023: `WARN en_target` требует ≥ 3 латинских слов (при китайском `source_cn`) **и** латиницы больше 2× кириллицы. Строки с коротким английским названием внутри русского текста под это правило не попадают.
- Оценка объёма после отсева отладочных: **≈1 000–1 500 видимых строк**.

## План

### R1. Правило `WARN en_name` в `tools/VerifyBatch.ps1`
- В `target_ru` снять теги `<…>`, `{…}`, `%x`, `\n`. Сработка, если есть серия ≥ 2 латинских слов, первое с заглавной (`[A-Z][a-z]{2,}`, далее слова с заглавной или `of/the/and/'s`, дефис, цифра).
- Исключения (только отладочные, как у `en_target`, плюс):
  - `source_cn` начинается с `[`/`【`/`(`, содержит идентификаторы (`\w+\.\w+`, camelCase, `_`), `测试|占位|模板|策划|程序|GM|test|Debug`, или устроен как «A-B-C» (2+ дефиса между короткими частями — заметки дизайнеров);
  - `target_ru` содержит `Заполнитель|Шаблон|шаблон|Тест|резервная копия` или «Эффект навыка Auto Chess-<число>»;
  - латинская серия встречается в самом `source_cn` (бренд или английское название в оригинале, например «Duet Night Abyss»).
- Вывести список в `temp/t026/en_name.csv` (`batch;id;source_cn;target_ru`) и счётчики по батчам. В TASK записать число срабатываний и 20 случайных строк из «сработало» и 20 из «исключено», чтобы проверить отсев глазами.

### R2. Перенос в батчи перевода (как И1/И3 TASK-023)
- Перенести строки `en_name` в новые батчи `batch_043_en_names_1.json`, `…_2`, … (≈400 строк на батч, по порядку исходных батчей) с пустым `target_ru`. Скрипт — на основе `temp/t023/move_en2.ps1` (если `temp/` очищен, написать заново: перенос текстовый, дубли `source_cn` в других батчах сначала проверить, после переноса — round-trip формата каждого затронутого батча).
- Дубли: если тот же `source_cn` с хорошим переводом (без `en_name`) есть в другом батче — не переносить, а записать в CSV `dup_ok`: такая строка уже показывает правильный текст по ключу.
- После переноса: `ShardCompiler`, `VerifyBatch` (0 ERR, `en_name` = 0, кроме известных ложных). До перевода эти строки показывают `ref_en`, так что релиз собирать только после перевода.

### R3. Теги и `{{variant}}` против `source_cn` (только проверка)
- В `VerifyBatch` для `Closing tag count mismatch` и `{{variant|variant}} count differs` сравнивать с `source_cn`, если он не пуст (сейчас сравнение с `ref_en`). Вывести, сколько из 84 + 32 остаются ошибками против `source_cn`. Реальные ошибки добавить в `temp/t026/tags.csv` — их переведёт тот же чат перевода (перенос как в R2, в `batch_043_en_names_tags.json`).

### Пачки перевода (чат перевода, `/translate-pack`, по одному батчу на чат)
- Переводить **заново по `source_cn`**, `ref_en` — ориентир. Все имена, Пути, Последовательности, места и предметы — строго по `source/glossary/*.json` (`-ExportNew` сам кладёт `terms` + `names`). Английских слов в результате не оставлять, кроме брендов, которые есть в `source_cn`.
- После каждого батча: `GlossaryCheck -Report` (B/C = 0), `VerifyBatch` (0 ERR, `en_name` = 0).

### Документы и релиз
- `docs/PROJECT_MAP.md`: `WARN en_name`, батчи `batch_043_*`. `docs/TRANSLATION_GUIDE.md`: правило «названия переводить, английские вставки недопустимы».
- Релиз — после всех пачек (или после каждой завершённой пачки, если пачек больше трёх).

## Проверка
- Автоматическая: `VerifyBatch` — 0 ERR, `en_name` = 0 кроме известных ложных; `GlossaryCheck -Report` — B/C = 0; `ShardCompiler` — 1024 шарда.
- Чек-лист для пользователя: открыть описания предметов в сумке (наряды Таро, «Тайный Соглядатай»), подсказки навыков в бою, диалоги в Тингене и Бэкленде (рестораны, газеты, улицы) — названия по-русски, без английских вставок.
