# Временная рабочая директория (Temp / Scratchpad)

Эта директория выделена специально для любых временных и промежуточных файлов:
- **Чанки переводов**: временные JSON-файлы для обмена с ИИ (`temp_chunk.json`, срезы батчей).
- **Сырые ответы моделей**: черновые варианты перевода, ответы нейросетей перед слиянием.
- **Одноразовые скрипты**: вспомогательные утилиты тестирования, скрипты отладки и проверки.
- **Дампы и логи**: промежуточные отчеты валидации, логи компилятора и экстрактора.

> [!TIP]
> **Безопасность удаления**: всё содержимое этой папки (кроме данного `README.md`) можно в любой момент безопасно очистить или удалить. Рабочие исходники проекта (`source/`, `patch_payload/`, `tools/`, `docs/`) от этого не пострадают.
