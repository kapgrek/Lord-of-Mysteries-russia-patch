# AbsoluteRU — правила для ИИ-агента

Русская локализация Lord of the Mysteries: Lua-рантайм поверх CPDD и установщик. Карта репозитория и таблица «задача → файл» лежат в [docs/PROJECT_MAP.md](docs/PROJECT_MAP.md), уроки прошлых инцидентов собраны в [docs/LESSONS.md](docs/LESSONS.md). Отвечать пользователю **на русском**.

## 1. Игра на ПК пользователя: только чтение
- Папку установленной игры (`D:\Games\GMZZLauncher\Game\C7`, `D:\Game\…` и любую другую вне репозитория) можно **читать**: логи (`Saved\Logs\C7.log`), установленный патч, конфиги. Можно распаковывать и выгружать данные из паков и файлов игры в `reference/` или `temp/`.
- **Запрещено** создавать, изменять, удалять и перемещать файлы в папке игры, а также запускать игру, лаунчер и установщик. Логику установщика проверять тестами `tools/InstallerCoreTests.exe` на поддельных папках в `temp/`. Установку и проверку в игре делает только пользователь. Запрет дублируется хуком `.claude/hooks/guard-game.ps1`.

## 2. Git
- Не переписывать историю (`rebase`, `reset --hard`, `push --force`, `filter-*`) и не удалять теги без прямой просьбы пользователя.
- `commit` и `push origin main` разрешены в чате исполнения. Бинарники (`*.exe`, архивы) в git не коммитятся: их собирают `tools/BuildTools.ps1` и `tools/PackageRelease.ps1`, а публикуются они как assets GitHub Release (`PackageRelease.ps1 -Publish`).

## 3. Два чата: анализ отдельно, решение отдельно
- **Чат 1 (анализ):** найти первопричину со ссылками `файл:строка` и подтверждением из логов, записать план в `docs/tasks/TASK-xxx.md`, выдать готовый промпт для чата 2. Кроме TASK-файла, ничего не править и код исправления не писать. В конце написать: «Анализ завершён. Для реализации откройте новый чат».
- **Чат 2 (исполнение):** выполнить план из TASK-файла, проверить результат, закоммитить, при необходимости собрать и опубликовать релиз.

## 4. Первопричина и проверка
- Прежде чем править, подтвердить гипотезу логами или дампами реальных данных. Нельзя править «на удачу» регулярки, фильтры и тайминги.
- Не писать «исправлено», пока пользователь не проверит в игре. Вместо этого дать чек-лист: что открыть, что должно быть видно, какую строку искать в `C7.log`.
- Новая диагностика и подробные логи включаются только при `DiagnosticsMode = true` (`bootstrap.lua`). В обычном режиме лог остаётся тихим.

## 5. Файлы и кодировки
- `temp/`: одноразовые скрипты, дампы, сырые ответы. Пользователь может очистить эту папку в любой момент, поэтому ничего невосстановимого там не хранить.
- `reference/`: внешние материалы (английский патч CPDD, выгрузки из игры). Папка не в git и **не очищается**.
- Не создавать служебные файлы в корне, `source/`, `docs/`, `tools/`, `patch_payload/`.
- Все текстовые файлы в **UTF-8 без BOM** с концами строк **LF** (см. `.gitattributes`). `lua/cpdd_translation/**` содержит байткод LuaJIT: его не открывать как текст и не конвертировать.
- Поиск всегда ограничивать папкой или исключать сгенерированное: `RuntimeTextGemini_*`, `LanguageSourceIndex_*`, `BakedText/`, `temp/`, `reference/` (см. `.ignore`).

## 6. Перевод
- Источник истины: `source/translation_batches/batch_*.json` (поле `target_ru`), глоссарий в `source/glossary/` и `docs/GLOSSARY.md`. Файлы в `patch_payload/` генерируются, руками их не править.
- Переводить смысл `source_cn`, а `ref_en` использовать как ориентир. Плейсхолдеры (`%s`, `{0}`, `\n`) и теги (`<Highlight>`, `</>`) сохранять без изменений. Подробности в [docs/TRANSLATION_GUIDE.md](docs/TRANSLATION_GUIDE.md).
- После правок батчей нужно запустить `tools/ShardCompiler.exe` и `tools/VerifyBatch.ps1`. Хук Stop (`.claude/hooks/recompile-shards.ps1`) делает это автоматически для изменённых батчей.
