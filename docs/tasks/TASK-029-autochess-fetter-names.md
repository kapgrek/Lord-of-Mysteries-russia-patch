## Канон (решение пользователя 2026-10-05)
- **羁绊 → «резонанс»** (в подписях «Резонанс», во фразах «дает резонанс 【X】»). «Связь», «узы», «синергия» в контексте Автошахмат запрещены. Исключение — не-Автошахматные строки про отношения людей («宿命的羁绊», «你的誓约迎来新的羁绊»): там остаётся «связь/узы» → в `cn_exclude`.
- **铁卫 → «Железная стена»**, **施法者 / 施法 → «Колдовство»** (как в подписях на панели).
- **窥秘人 → «Тайновидец»** (предложение, ждёт подтверждения пользователя; альтернатива пользователя — «Искатель тайн»). Довод: 窥 = «подглядывать, видеть тайком», «Тайновидец» сохраняет этот смысл, короткий для подписи и в одном ряду с «Провидец» (占卜家). «Искатель» теряет «видение» и ближе к 探秘/寻秘. Канон действует **во всей игре** (это путь), а не только в Автошахматах.
- Остальное по большинству и глоссарию путей:
  神弃之地 «Заброшенная земля богов», 磐石 «Скала», 生命教派 «Секта Жизни» (в ряд с «Секта Смерти», «Секта Демониц»), 超凡生物 «Потустороннее существо» (канон «Потусторонний» = Beyonder, TASK-022), 阅读者 «Читатель» (глоссарий путей), 秘祈人 «Молящийся о Секретах», 耕种者 «Плантатор», 执法者 «Юрист», 魔女教派 «Секта Демониц», 隐秘学派 «Школа Тайн», 通识者 «Знаток», 狂战士 «Берсерк», 巨龙传承 «Наследие Гигантского Дракона», 黑夜女神 «Богиня Вечной Ночи», 塔罗会 «Клуб Таро», 值夜者 «Ночной Ястреб» / мн. «Ночные Ястребы».

## План

### R1. Глоссарий `source/glossary/autochess_fetters.json`
Формат как в `ui_traintrade.json` (`cn`, `en`, `ru`, `ru_match`, `forbidden`, `cn_exclude`, `note`). Термины:
- `羁绊`: `ru_match` `резонанс`, `forbidden` `["\\bсвяз", "\\bуз(ы|ам|ами|ах|\\b)", "синерги"]`, `cn_exclude` — строки про отношения (`宿命的羁绊`, `誓约迎来新的羁绊`, `隐秘羁绊` — **проверить** по отчёту: «тайная связь Дейли/Азика» в Автошахматах это или в системе спутников; если спутники — исключить). Учесть урок памяти *glossary-cn-exclude-substring*: `cn_exclude` работает по подстроке.
- Все 42 имени из таблицы выше, `forbidden` — найденные неверные варианты (`монолит|камень`, `школа мысли жизни|жизненная школа`, `тайна прайер|тайн\\w* прайер|прайер|подглядывающ|тайновед|жрец тайн`, `сверхъестественн\\w* существ`, `\\bчтец`, `провидец` для 秘祈人, `садовник`, `правоохранител`, `ведьм`, `школа отшельник`, `железн\\w* страж`, `савант`, `берсеркер`, `наследств`, `заклинател` для 施法者, `вечной богин` и т. п.).
- Короткие `cn` (`磐石`, `铁卫`, `猎人`, `战士`, `法师`, `怪物`, `黑夜`, `水手`, `歌者`, `观众`) ловят ложные совпадения вне Автошахмат: прогнать `-Report`, посмотреть корзины и сузить `cn` / добавить `cn_exclude` **до** правки. `战士` ⊂ `狂战士`, `施法` ⊂ `施法者`, `黑夜` ⊂ `黑夜女神` — через `parent` или маскировку.
- 窥秘人 — отдельной записью (весь клиент), а также добавить в `pathways_and_sequences.json`, если пользователь подтвердит канон.
