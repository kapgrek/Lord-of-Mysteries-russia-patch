# Регламент работы чатов-переводчиков (AI Workflow Guide)

Данный документ описывает оптимальный процесс перевода игровых текстов Lord of the Mysteries через сторонние нейросетевые чаты (Claude 3.5 Sonnet, GPT-4o, Gemini 1.5/2.0 Pro, DeepSeek V3) с минимальными затратами токенов и максимальной скоростью.

---

## 1. Главные проблемы при работе с ИИ

| Проблема | Почему это происходит | Как мы это решили |
|---|---|---|
| **Обрыв ответа (Cutoff)** | Файл батча содержит 5 000 строк (~1 МБ), а лимит генерации ИИ — 4 096–8 192 токенов (~250 строк). | Нарезка батча на микро-чанки по **100–150 строк** с помощью утилиты `BatchHelper.ps1`. |
| **Огромный расход токенов** | Если просить ИИ возвращать полный JSON (`id`, `source_cn`, `ref_en`, `target_ru`), 75% токенов тратятся на повторение того же текста. | ИИ возвращает **только словарь дельты**: `{"000001": "Перевод"}`. |
| **«Галлюцинации» и вежливость** | ИИ пишет «Конечно! Вот ваш перевод:», тратя токены и ломая формат JSON. | Системный промпт `AI_TRANSLATOR_PROMPT.md` запрещает любой текст вне JSON. |
| **Поломка тегов движка** | ИИ переводит названия тегов `<Highlight>` -> `<Подсветка>` или теряет `%s`. | Автоматический валидатор `VerifyBatch.ps1` проверяет батч перед компиляцией. |

## 2. Пошаговый пайплайн перевода одного батча

### Шаг 1. Открытие чата и ввод системного промпта
1. Создайте новый диалог в выбранной модели (рекомендуются: Claude 3.5 Sonnet, GPT-4o, Gemini 2.0 Flash / Pro).
2. Скопируйте и отправьте текст из [`docs/AI_TRANSLATOR_PROMPT.md`](./AI_TRANSLATOR_PROMPT.md).
3. Модель подтвердит готовность (или сразу будет ждать данные).

> [!TIP]
> **Ускорение в 1 клик (`-IncludePrompt`):**  
> При экспорте добавьте флаг `-IncludePrompt`:
> ```powershell
> .\tools\BatchHelper.ps1 -Action Export -Batch 1 -Count 100 -IncludePrompt
> ```
> Скрипт сам объединит системные правила, глоссарий и массив строк, поместив всё в буфер обмена. В новом чате достаточно просто нажать `Ctrl+V`!

### Шаг 2. Выгрузка компактного чанка с контекстом
Используйте скрипт `tools/BatchHelper.ps1`, чтобы получить порцию непереведенных строк:
```powershell
# Экспортировать следующие 100 непереведенных строк из batch_001.json
.\tools\BatchHelper.ps1 -Action Export -Batch 1 -Count 100
```
Скрипт скопирует компактный JSON прямо в буфер обмена и сохранит в `temp/temp_chunk.json`.

Формат чанка на вход ИИ (каждая строка снабжена контекстным маркером `ctx`, решающим проблему FNV-1a перемешивания):
```json
[
  { "id": "000001", "ctx": "General", "cn": "...", "en": "..." },
  { "id": "000002", "ctx": "Achievement/QuestTitle", "cn": "...", "en": "..." },
  { "id": "000007", "ctx": "SkillLink", "cn": "...", "en": "..." },
  { "id": "000008", "ctx": "DialogueEmotion", "cn": "...", "en": "..." },
  { "id": "000045", "ctx": "BakedText/KeepEmpty", "cn": "...", "en": "" }
]
```

> [!IMPORTANT]
> **Поле `ctx` (Контекст строки):**  
> Поскольку в UE5 строки рантайма шардируются алгоритмом хеширования FNV-1a, в батче перемешаны навыки, диалоги и меню. Маркер `ctx` подсказывает модели точный тип строки (`SkillLink` — боевой скилл, `DialogueEmotion` — реплика NPC, `BakedText/KeepEmpty` — запеченная кнопка, оставить пустой `""`).

### Шаг 3. Отправка в ИИ и получение перевода
Вставьте данные в чат с фразой:
> Переведи строки:
> [вставка из буфера обмена]

ИИ выдаст компактный ответ:
```json
{
  "000001": "Текст перевода...",
  "000002": "Второй перевод..."
}
```

### Шаг 4. Внедрение перевода обратно в батч
Скопируйте полученный JSON-ответ ИИ в буфер обмена (или сохраните в файл) и запустите:
```powershell
# Применить перевод из буфера обмена обратно в batch_001.json
.\tools\BatchHelper.ps1 -Action Import -Batch 1 -FromClipboard
```
Скрипт мгновенно обновит поле `target_ru` у соответствующих ID в файле `batch_001.json`.

## 3. Параллельная работа в нескольких соседних чатах/папках

Если вы переводите одновременно в нескольких окнах чатов (или в нескольких рабочих папках-воркерах):

### Вариант А: Автогенерация папок-воркеров (`SetupWorkers`)
Сгенерируйте готовые пакеты для 3–5 параллельных чатов одной командой:
```powershell
# Создать 3 независимых пакета по 100 строк для Батча 1
.\tools\BatchHelper.ps1 -Action SetupWorkers -Batch 1 -Count 100 -WorkerCount 3
```
В папке `temp/workers/` будут созданы папки `batch_001_worker_01`, `worker_02`, `worker_03`:
* В каждой папке лежит файл `TASK_PROMPT.txt` (готовый промпт со 100 уникальными строками без наложения).
* Батник `import.bat` — запускается в 1 клик для применения файла `result.json`.
* Батник `import_clipboard.bat` — в 1 клик накатывает перевод прямо из буфера обмена и валидирует батч.

### Вариант Б: Ручное смещение (`-Skip`)
Если вы работаете в ручном режиме с двумя-тремя чатами над одним батчем:
```powershell
# Чат 1: берет первые 100 непереведенных строк
.\tools\BatchHelper.ps1 -Action Export -Batch 1 -Count 100 -IncludePrompt

# Чат 2: берет следующие 100 непереведенных строк (со смещением 100)
.\tools\BatchHelper.ps1 -Action Export -Batch 1 -Count 100 -Skip 100 -IncludePrompt

# Чат 3: берет следующие 100 строк (со смещением 200)
.\tools\BatchHelper.ps1 -Action Export -Batch 1 -Count 100 -Skip 200 -IncludePrompt
```
Чаты работают параллельно без коллизий! Результаты каждого можно импортировать в любом порядке.

## 4. Сводный дашборд прогресса

В любой момент вы можете оценить общий прогресс проекта по всем 27 батчам:
```powershell
.\tools\BatchHelper.ps1 -Action Dashboard
```
Команда выведет наглядную таблицу готовности всех батчей и автоматически обновит статус в манифесте `source/translation_batches/BATCH_MANIFEST.md`.

---

## 5. Проверка качества и компиляция в игру

После перевода нужного количества строк:
1. Запустите валидатор:
   ```powershell
   .\tools\VerifyBatch.ps1 -Batch 1
   ```
2. Скомпилируйте батчи в игровые 1 024 шарда:
   ```powershell
   .\tools\ShardCompiler.exe
   ```
3. Проверьте целостность дистрибутива:
   ```powershell
   .\tools\VerifyPatch.ps1
   ```

## 6. Таблица оптимальных параметров для разных моделей

| Модель | Оптимальный чанк | Режим ввода | Особенности |
|---|---|---|---|
| **Claude 3.5 Sonnet** | 120–150 строк | Ввод в веб-чат или API | Идеально держит теги и литературный стиль |
| **GPT-4o** | 100–120 строк | Ввод в веб-чат или API | Высокая скорость, строгий JSON |
| **Gemini 2.0 Flash / Pro** | 150–200 строк | Google AI Studio / Web | Огромное контекстное окно, минимальная стоимость |
| **DeepSeek V3 / R1** | 100 строк | Веб-чат / API | Отличное понимание китайского оригинала |
